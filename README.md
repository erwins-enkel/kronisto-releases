# Kronisto releases

Update feed for [Kronisto](https://github.com/erwins-enkel/kronisto), the on-device dictation and
meeting-notes app for macOS (formerly Murmur). Kronisto checks `appcast.xml` (Sparkle) daily; the
notarized builds are attached to this repo's releases.

Published by `scripts/release.sh --publish` in the app repo. Updates are signed (EdDSA); the
public key is in the app's `Info.plist`.
